## Sobre mim

> Eu não gosto de software que apenas responde. Gosto de software que observa, lembra, decide e consegue explicar o que fez.

Sou **Engenheiro de IA e Backend**, atualmente trabalhando com produtos de IA aplicados a sistemas reais. Minha atuação passa por agentes, RAG, memória, voz, arquitetura distribuída, APIs e integração de modelos com software tradicional.

Também construo projetos experimentais em que engenharia e identidade visual andam juntas: assistentes locais, protocolos para agentes de código, interfaces narrativas e ferramentas que tentam parecer menos um dashboard genérico e mais um sistema com personalidade.
